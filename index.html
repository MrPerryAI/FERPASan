        How it works

        1

        Finds names

        Uses your class list, column headings like “Student Name”, and built-in lists of over 10,000 first names and 25,000 last names. You approve every one.

        2

        Swaps in code names

        Each student gets a random code name like Fluffy Unicorn 45. “Emma” becomes “Fluffy” and “Johnson” becomes “Unicorn 45”, so the writing still reads naturally.

        3

        Keeps a private key

        The key lists who is who. It stays with you, so you can put the real names back into whatever the AI writes.

        Why code names like “Fluffy Unicorn 45”?
        • Random, not reversible. Code names are picked at random. They don't use initials, so they reveal nothing about the student.
        • Consistent. The same student gets the same code name in every file you process together, or later if you reuse the key. Siblings share the animal part, just like a real family name.
        • Easy to put back. Silly words like “Fluffy” almost never appear in schoolwork, so swapping real names back in is accurate.
        • Number = unique. The number keeps two students apart even if their code names look alike.
        Is this really offline?

        Yes. This page has no server and makes no network requests. You can turn off Wi-Fi and it still works. Download the single-file version, save it to your desktop, and double-click it any time.

        What it can't do
        • Read text inside pictures, screenshots, or scanned PDFs. It tells you when a file has pictures so you can check them.
        • Keep a PDF's layout. PDFs come out as a clean text file, which is what AI tools read best anyway.
        • Open old .doc/.xls/.ppt files. Save them as .docx/.xlsx/.pptx first (it takes 10 seconds and the tool tells you how).
        • Promise perfection. Always skim the result before you share it. This tool helps you follow FERPA, but it isn't legal advice.
