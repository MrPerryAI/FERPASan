How it works

1

Add your files. Paste your class list too, so it catches every name.

2

Check the names. You see every name it found and approve each one.

3

Download. Give the sanitized file to AI. Keep the private key to yourself.

4

Put names back. Paste the AI's answer and the real names return.

It works on the real file, not just pasted text

  • Formatting, fonts and layout are kept
  • Word tables, headers, footers and comments
  • Excel formulas, sheet names and student ID columns
  • PowerPoint slides and speaker notes
  • Tracked changes and alt text on pictures
  • Emails, phone numbers and student IDs
  • Same code names every week if you reuse your key
  • PDFs come out as clean text for AI
